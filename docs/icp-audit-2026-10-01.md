## Fix strategy (recommended order)
1. Replace every `useIcpLab`-only guard with `resolveAuthBackend()==="icp"` / `isFeatureRoutedToIcp` (mechanical, kills systemic problem 1)
2. Gate the BREAK write paths (chat send, event card RSVP, team-member adds, pitch board, club settings, seasons/EOI, competitions, payments)
3. (REVISED per user directive 2026-10-01) Do NOT add "not available" UI states. Instead close every gap: route ALL ~60 DEGRADED reads to real ICP data — wire to existing canister methods or add missing canister shapes and wire them. No read may silently return empty/stale under ICP.
4. Auth surfaces: hide password/passkey/OTP UI for II users; gate account delete/export
